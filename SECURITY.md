# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Report
them privately to the repository maintainers with a description of the issue,
the affected component, reproduction steps, and any relevant impact.

KarenPay is an experimental consent layer for PayPal's sandbox. It is not a
bank, wallet, or production payment system, and it does not claim to be
certified, compliant, or safe for real money.
