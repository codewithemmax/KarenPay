# KarenPay
KarenPay is an open-source consent layer that stops AI agents from moving money unless the account owner hears the exact action read aloud and approves it with a passkey (fingerprint or face). Built for voice-first use by blind and low-vision users, it sends payments through PayPal’s sandbox.

See the [architecture diagram](docs/ARCHITECTURE.md) for the runtime
boundaries, consent sequence, and mandate lifecycle.
